# EmojiCombos.com — Live Search Tool

Live searchable database at [emojicombos.com](https://emojicombos.com/) for discovering emoji and symbol combinations. Pair it with a local combos file of favourites you have already vetted.

## URL Pattern

```
https://emojicombos.com/<search-term>
```

Examples: `emojicombos.com/goth-heart`, `emojicombos.com/divider-symbols`, `emojicombos.com/bow`

## House Style: Symbols Over Emojis

**Prefer pure Unicode symbols over emoji-heavy combos.** The site leans emoji by default — always favor results that are symbol-dense rather than emoji-dense. When presenting search results, prioritize and highlight the symbol-forward combos.

## How to Use via Browser

Navigate to the URL and use `browser_snapshot()` to skim results. Every result has a copy button. Related links at the bottom of each result allow rabbit-holing into adjacent categories.

## Integration

Use as a live discovery tool when your local combos file doesn't have what you need. Search, extract the best symbol-forward combos, and present them. Cache the good ones locally so repeat requests don't need a browser trip.
